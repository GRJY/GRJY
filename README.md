- 📱 Native iOS & macOS with Swift 6 Concurrency (Actors), SwiftUI, Combine, MapKit, CryptoKit
- 🌐 Full stack web — PHP/Laravel, MySQL, JavaScript, AWS (Lambda, DynamoDB), REST APIs
